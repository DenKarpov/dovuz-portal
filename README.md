# ДоВуз-Портал

Монорепозиторий проекта. Продолжение ВКР Купцовой П.Д. «Веб-приложение для
автоматизации бизнес-процессов в подразделении довузовского образования»
(АИС «ДоВуз-Портал») в рамках предмета «Проектная деятельность».

## Структура

| Каталог | Что это |
|---|---|
| `frontend/` | React + TypeScript. Перенесён из репозитория автора ВКР с сохранением истории |
| `backend/` | Python-бэкенд. Появится следующим шагом |

## Фронтенд

React 18 + TypeScript + Tailwind + shadcn/ui, собран на Create React App.

```bash
cd frontend
npm install
npm start          # http://localhost:3000
```

Весь HTTP заперт в слое `src/app/api/` — прямых вызовов из страниц нет.
Единственная точка подключения к бэкенду: `src/app/api/axios.ts`,
`BASE_URL = http://localhost:8080/v1`, аутентификация сессионной кукой
(`withCredentials: true`, JWT нет). Контракт — около 105 эндпоинтов.

## Бэкенд

От Java (Spring Boot), на которой была написана ВКР, отказались — бэкенд пишем
на Python заново. Контракт снимаем со слоя `frontend/src/app/api/` в OpenAPI-спеку;
она становится источником правды для обеих сторон: из неё генерируются pydantic-модели
для бэкенда и типизированный клиент для фронта взамен рукописного слоя `api/`.

## История

Коммиты до переноса принадлежат Купцовой П.Д. (март — май 2026). Рабочая копия
из переданного архива оказалась новее последнего её коммита на 1818 строк —
этот снимок зафиксирован отдельным коммитом с сохранением её авторства.
