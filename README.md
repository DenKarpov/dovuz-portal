# ДоВуз-Портал

Монорепозиторий проекта. Продолжение ВКР Купцовой П.Д. «Веб-приложение для
автоматизации бизнес-процессов в подразделении довузовского образования»
(АИС «ДоВуз-Портал») в рамках предмета «Проектная деятельность».

## Структура

| Каталог | Что это |
|---|---|
| `frontend/` | React + TypeScript. Перенесён из репозитория автора ВКР с сохранением истории |
| `backend/` | Python-бэкенд: OpenAPI-контракт и сгенерированный из него слой FastAPI |

## Фронтенд

React 18 + TypeScript + Tailwind + shadcn/ui, собран на Create React App.

```bash
cd frontend
npm install
npm start          # http://localhost:3000
```

Весь HTTP заперт в слое `src/app/api/` — прямых вызовов из страниц нет.
Единственная точка подключения к бэкенду: `src/app/api/axios.ts`,
`BASE_URL = http://localhost:8080/v1`, аутентификация сессионной кукой
(`withCredentials: true`, JWT нет). Всего фронт вызывает 135 пар «метод + путь».

## Бэкенд

От Java (Spring Boot), на которой была написана ВКР, отказались — бэкенд пишем
на Python заново. Контракт снимаем со слоя `frontend/src/app/api/` в OpenAPI-спеку
[`backend/openapi/`](backend/openapi/), разбитую по тегам; она — источник правды
для обеих сторон. Из неё генерируются pydantic-модели и роуты FastAPI, а позже —
типизированный клиент для фронта взамен рукописного слоя `api/`.

Первый заход — 58 операций: вход и регистрация, профили и пользователи, роли,
материалы (направления, предметы, темы, публикации), новости, комментарии, файлы,
школы и классы, модераторы предметов. Реализаций ручек пока нет, каждая отвечает 501.
Подробности — в [`backend/README.md`](backend/README.md).

## Как вносить изменения

Напрямую в `main` пушить нельзя — GitHub отклонит. Порядок такой:

1. Ветка от свежего `main`: `git fetch && git switch -c <о-чём-ветка> origin/main`.
2. Коммиты, `git push -u origin <о-чём-ветка>`, PR в `main`.
3. В PR должны позеленеть проверки `backend` и `frontend`, закрыться все треды ревью
   и появиться ОК владельца кода из [`.github/CODEOWNERS`](.github/CODEOWNERS).
   Если `main` ушёл вперёд, ветку нужно подтянуть — кнопка «Update branch».
4. Мёрж только squash: в `main` попадает один коммит с заголовком PR, ветка удаляется.
   Можно включить автомёрж — PR вмёржится сам, когда всё позеленеет.

## История

Коммиты до переноса принадлежат Купцовой П.Д. (март — май 2026). Рабочая копия
из переданного архива оказалась новее последнего её коммита на 1818 строк —
этот снимок зафиксирован отдельным коммитом с сохранением её авторства.
